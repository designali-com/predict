Each biomarker has its own page with a live reference range card, what it measures, how to read a high or low result, and notes on testing.

## How to read a range

Every biomarker has a healthy range, read as the middle 95% of healthy values. From that:

- **Mean** is `(low + high) / 2`.
- **SD** is `(high − low) / 4`.
- **Z-score** is `(value − mean) / SD`. Inside the range, Z is between −2 and +2.

**Direction** says which way is bad:

| Direction | Meaning |
| --- | --- |
| ↑ Bad | A raised value is the concern. A low one is not flagged as a concern. |
| ↓ Bad | A lowered value is the concern. |
| Normal best | Either side is a concern. |
| Context | Either side may matter, depending on the person. |

The card colour steps up with |Z| using the status colours. See [Reference Range](/docs/tools/reference-range) for the full scale.

## Indices

Groups of these biomarkers are combined into composite scores, such as the [CBMI](/biomarkers/indices/cbmi) and [CBVAI](/biomarkers/indices/cbvai). See [Indices](/biomarkers/indices) for all five and how they are calculated.

## In code

The list is in `@workspace/ui/lib/biomarkers`, with the same ids as these pages.

```tsx
import { biomarkerRange, getBiomarker } from "@workspace/ui/lib/biomarkers"
import { ReferenceRange } from "@workspace/ui/tools/reference-range"

const crp = getBiomarker("hs-crp")!

<ReferenceRange
  name={crp.abbreviation}
  description={crp.name}
  value={3.5}
  unit={crp.unit}
  range={biomarkerRange(crp)}
/>
```
