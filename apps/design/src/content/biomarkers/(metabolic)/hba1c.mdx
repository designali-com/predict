## What it measures

Glycated haemoglobin is haemoglobin with glucose attached. Red blood cells last about three months, so it reflects average glucose over that time.

## Reference range

| Field | Value |
| --- | --- |
| Abbreviation | HbA1c |
| Group | Glucose and insulin |
| Unit | % |
| Healthy range | 4–5.6 |
| Mean | 4.8 |
| SD | 0.4 |
| Direction | ↑ Bad — a raised value is the concern. |

The mean is `(low + high) / 2` and the SD is `(high − low) / 4`, so the healthy range covers Z from −2 to +2.

## Reading the result

- **High** — 5.7 to 6.4% suggests prediabetes and 6.5% or more suggests diabetes.
- **Low** — Not a concern.

## Notes

- Anaemia, recent blood loss, and some haemoglobin variants make it less reliable.
- This page is general information, not medical advice. Discuss results with a clinician.
