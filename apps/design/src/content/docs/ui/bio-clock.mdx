## Usage

Use the bio clock to sum up a person's results on one dial. It has three hands:

- **Domain hand** — The dashed hand on the outer arc. It points at the domain with the highest `value`.
- **Severity hand** — The solid hand on the inner arc, with a bubble showing the score as given, such as `1.1`.
- **Age hand** — The thick hand on the lower scale, from 0 to 100. The badge shows `yearsValue` and the biological age, such as `+4 Years (51)`.

Hover or focus a domain on the outer arc to see a tooltip with its full name and value.

Import it from `@workspace/ui/predict/bio-clock`.

```tsx
import { BioClock } from "@workspace/ui/predict/bio-clock"
```

```tsx
<BioClock bioAge={42} yearsValue="-3 Years" currentValue={0.6} />
```

### Defaults

- **Domains** — Seven segments: IFR, VAF, MHF, BMF, PNF, CMF, and RFF, each with a full name for its tooltip. PNF has the highest value, so the domain hand points at it.
- **Severity** — A 0 to 5 scale in five steps, coloured `--status-normal`, `--status-mild`, `--status-moderate`, `--status-severe`, and `--status-extreme`. The score is 1.1.
- **Age** — `bioAge` is 60, and the badge shows `+7 YEARS (60)`. Always pass `yearsValue` with real data, or the badge shows the placeholder.

### Notes

- The clock fills its container's width. Set the size on the parent or with `className`.
- `currentValue` replaces `severity.current`, so you can keep one scale and change only the score.
- The age hand stops at 0 and 100. The severity hand does not, so keep `currentValue` inside the scale.
- When two domains share the highest value, the hand points at the first.
- Colours are any CSS colour. Use the `--color-status-*` variables to follow the theme.
- The bubble and badge show numbers as you pass them. Round them first, such as `Math.round(age * 10) / 10`.
- Each domain can be reached with Tab, which opens its tooltip.

## Props

Unlisted props pass through to the wrapping `div`, which also takes a `ref`.

### BioClock

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `bioAge` | `number` | `60` | Biological age, placed on the 0 to 100 scale. |
| `yearsValue` | `string` | `+7 YEARS` | The gap from real age, such as `+4 Years`. Shown in the badge. |
| `yearsDiff` | `string` | — | Same as `yearsValue`. `yearsValue` wins when both are set. |
| `currentValue` | `number` | `1.1` | The severity score. Replaces `severity.current`. |
| `severity` | `SeverityScale` | 0 to 5, five steps | The scale on the inner arc. |
| `domains` | `DomainSegment[]` | seven domains | The segments on the outer arc. |
| `segments` | `Segment[]` | — | Older form of `domains`. A missing `value` becomes 10, 20, 30, and so on. Ignored when `domains` is set. |
| `className` | `string` | — | Classes merged onto the wrapper. |

### DomainSegment

| Field | Type | Description |
| --- | --- | --- |
| `label` | `string` | Short name shown outside the arc, such as `HRT`. |
| `fullName` | `string` | Full name shown in the tooltip, such as `Heart health`. |
| `color` | `string` | Segment colour. |
| `value` | `number` | Shown in the tooltip. The domain hand points at the highest. |

`Segment` has `label`, `color`, and an optional `value`. Its tooltip shows the `label` as the name.

### SeverityScale

| Field | Type | Description |
| --- | --- | --- |
| `ranges` | `SeverityRange[]` | Steps from low to high. The arc runs from the first `min` to the last `max`. |
| `current` | `number` | The score. Overridden by `currentValue`. |

### SeverityRange

| Field | Type | Description |
| --- | --- | --- |
| `min` | `number` | Start of the step. |
| `max` | `number` | End of the step. |
| `color` | `string` | Colour at the middle of the step. The arc blends between steps. |

`ClockGaugeProps` is the type of the props.
