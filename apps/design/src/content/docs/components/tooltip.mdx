## Usage

Use a tooltip to name an icon button or add a brief hint. Keep it to a few words. Never put information the reader needs only in a tooltip. Touch screens have no hover. For longer content or links, use a [Popover](/docs/components/popover).

Import it from `@workspace/ui/components/tooltip`.

```tsx
import {
  Tooltip,
  TooltipContent,
  TooltipProvider,
  TooltipTrigger,
} from "@workspace/ui/components/tooltip"
```

```tsx
<TooltipProvider>
  <Tooltip>
    <TooltipTrigger render={<Button size="icon" aria-label="Download" />}>
      <DownloadIcon />
    </TooltipTrigger>
    <TooltipContent>Download</TooltipContent>
  </Tooltip>
</TooltipProvider>
```

### Anatomy

- **TooltipProvider** — Shares the delay between tooltips. Wrap your app once.
- **Tooltip** — Holds the open state.
- **TooltipTrigger** — The element that shows the tooltip. Pass a button through `render`.
- **TooltipContent** — The label and its arrow.

### Notes

- The tooltip opens on hover and on keyboard focus.
- An icon button still needs its own `aria-label`. The tooltip does not name it.

## Props

These are the props you set most often. Unlisted props pass through to the underlying element.

### TooltipProvider

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `delay` | `number` | `0` | Milliseconds before a tooltip opens. |

### TooltipContent

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `side` | `"top", "right", "bottom", "left", "inline-start", or "inline-end"` | `top` | Side of the trigger to open on. |
| `align` | `"start", "center", or "end"` | `center` | Alignment along that side. |
| `sideOffset` | `number` | `4` | Gap from the trigger in pixels. |
| `className` | `string` | — | Classes merged onto the label. |
