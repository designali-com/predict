## Usage

Use a slider when the exact number matters less than its position in a range, such as average sleep or a target band. When the reader needs an exact value, use an [Input](/docs/components/input), or show the value next to the slider.

Import it from `@workspace/ui/components/slider`.

```tsx
import { Slider } from "@workspace/ui/components/slider"
```

```tsx
<span id="glucose-label">Target glucose range</span>
<Slider aria-labelledby="glucose-label" defaultValue={[70, 100]} min={40} max={200} />
```

### Anatomy

- **Slider** — Track, filled range, and one thumb per value.

### Notes

- Always pass `defaultValue` or `value` as an array. One item gives one thumb, two items give a range.
- Every slider needs a name. Point `aria-labelledby` at a visible label. `aria-label` on the slider only names the outer group, not the thumbs.
- Arrow keys move by `step`. Page Up and Page Down move by larger steps.

## Props

These are the props you set most often. Unlisted props pass through to the underlying element.

### Slider

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `defaultValue` | `number[]` | — | Value on first render. |
| `value` | `number[]` | — | Value when controlled. |
| `onValueChange` | `(value) => void` | — | Called while the value changes. `value` is a number or an array. |
| `onValueCommitted` | `(value) => void` | — | Called once when the reader lets go. |
| `min` | `number` | `0` | Lowest value. |
| `max` | `number` | `100` | Highest value. |
| `step` | `number` | `1` | Amount each step moves. |
| `largeStep` | `number` | `10` | Amount Page Up and Page Down move. |
| `orientation` | `"horizontal" or "vertical"` | `horizontal` | Direction of the track. |
| `disabled` | `boolean` | `false` | Blocks input and dims the slider. |
