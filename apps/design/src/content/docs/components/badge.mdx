## Usage

Use a badge to tag something with a short status, such as "In range" or "New". Keep it to one or two words.

Import it from `@workspace/ui/components/badge`.

```tsx
import { Badge } from "@workspace/ui/components/badge"
```

```tsx
<Badge variant="outline">In range</Badge>
```

### Notes

- A badge is a `span` by default. Pass `render` to make it a link.
- Mark an icon with `data-icon="inline-start"` or `data-icon="inline-end"` so the padding adjusts.
- Do not rely on colour alone for status. Put the status in the text, too.

## Props

Unlisted props pass through to the rendered element.

### Badge

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `"default", "secondary", "outline", "destructive", "ghost", or "link"` | `default` | Visual style. |
| `render` | `ReactElement` | — | Element to render instead of a `span`, such as `<a href="..." />`. |
| `className` | `string` | — | Classes merged onto the badge. |

`badgeVariants` is also exported, for giving another element the badge style.
