## Usage

Use a navigation menu for the main links of a site header. Each item is either a trigger that opens a panel of links, or a link on its own. For actions on the current page, such as an account menu with "Sign out", use a [dropdown menu](/docs/components/dropdown-menu).

Import it from `@workspace/ui/components/navigation-menu`.

```tsx
import {
  NavigationMenu,
  NavigationMenuContent,
  NavigationMenuItem,
  NavigationMenuLink,
  NavigationMenuList,
  NavigationMenuTrigger,
  navigationMenuTriggerStyle,
} from "@workspace/ui/components/navigation-menu"
```

```tsx
<NavigationMenu>
  <NavigationMenuList>
    <NavigationMenuItem>
      <NavigationMenuTrigger>Tests</NavigationMenuTrigger>
      <NavigationMenuContent>
        <NavigationMenuLink href="/tests/full-panel">Full panel</NavigationMenuLink>
      </NavigationMenuContent>
    </NavigationMenuItem>
    <NavigationMenuItem>
      <NavigationMenuLink href="/pricing" className={navigationMenuTriggerStyle()}>
        Pricing
      </NavigationMenuLink>
    </NavigationMenuItem>
  </NavigationMenuList>
</NavigationMenu>
```

### Anatomy

- **NavigationMenu** — The root. Renders a `nav` and the shared popup that holds every panel.
- **NavigationMenuList** — The row of items.
- **NavigationMenuItem** — One item in the row.
- **NavigationMenuTrigger** — Opens the item's panel on hover, focus or click. Shows a chevron that turns when open.
- **NavigationMenuContent** — The panel. Its contents move into the shared popup, which resizes between panels.
- **NavigationMenuLink** — A link, inside a panel or on its own in the row.
- **navigationMenuTriggerStyle** — Classes that make a **NavigationMenuLink** in the row match the triggers.

### Notes

- Give each panel a width, for example `w-72` on the list inside **NavigationMenuContent**. The popup sizes itself to the open panel.
- To use a router link such as `next/link`, pass it to `render`: `<NavigationMenuLink render={<Link href="/pricing" />}>Pricing</NavigationMenuLink>`.
- Set `active` on the link for the current page. It sets `aria-current="page"` and `data-active` for styling.
- The menu does not collapse on small screens. Hide it below a breakpoint and show the links in a [sheet](/docs/components/sheet) instead, as the header block does.

## Props

These are the props you set most often. Unlisted props pass through to the underlying Base UI part.

### NavigationMenu

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `align` | `"start" or "center" or "end"` | `"start"` | How the popup lines up with the open trigger. |
| `value` | `any` | — | Value of the open item, when controlled. |
| `defaultValue` | `any` | `null` | Value of the item open at first. |
| `onValueChange` | `(value) => void` | — | Called when an item opens or closes. |
| `delay` | `number` | `50` | Milliseconds of hover before a panel opens. |
| `closeDelay` | `number` | `50` | Milliseconds before a panel closes after the pointer leaves. |
| `className` | `string` | — | Classes merged onto the root. |

### NavigationMenuLink

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `href` | `string` | — | Where the link goes. |
| `active` | `boolean` | `false` | Whether the link is the current page. |
| `closeOnClick` | `boolean` | `false` | Whether clicking closes the menu. |
| `render` | `ReactElement` | — | Element to render instead of `a`, such as a router link. |
