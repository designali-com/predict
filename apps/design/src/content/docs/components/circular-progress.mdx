## Usage

Use circular progress for work in flight when space is tight: a file upload, a sync, results being processed. It fits beside a label, inside a button or in a card corner. Use a [progress bar](/docs/components/progress) when there is room for one, and a [gauge](/docs/components/gauge) to show a measurement rather than a task.

Import it from `@workspace/ui/components/circular-progress`.

```tsx
import {
  CircularProgress,
  CircularProgressIndicator,
  CircularProgressRange,
  CircularProgressTrack,
  CircularProgressValueText,
} from "@workspace/ui/components/circular-progress"
```

```tsx
<CircularProgress value={66} aria-label="Uploading results">
  <CircularProgressIndicator>
    <CircularProgressTrack />
    <CircularProgressRange />
  </CircularProgressIndicator>
  <CircularProgressValueText />
</CircularProgress>
```

For the common case, **CircularProgressCombined** renders the indicator, track, range and value text for you.

```tsx
import { CircularProgressCombined } from "@workspace/ui/components/circular-progress"

<CircularProgressCombined value={66} aria-label="Uploading results" />
```

### Anatomy

- **CircularProgress** — The root. Holds the value and geometry, and has the `progressbar` role.
- **CircularProgressIndicator** — The SVG that draws the ring. Put **CircularProgressTrack** and **CircularProgressRange** inside it.
- **CircularProgressTrack** — The full ring, in a muted colour.
- **CircularProgressRange** — The filled arc, up to the current value. It starts at the top and fills clockwise.
- **CircularProgressValueText** — The text centred over the ring. Defaults to a percentage.

### Notes

- Give the root an `aria-label` so screen readers know what is loading.
- Pass `getValueText` to change the text read by screen readers and shown by default. Pass children to **CircularProgressValueText** to change only what is shown.
- Colour the fill with a text colour class on **CircularProgressRange**, for example `text-chart-2`. The ring uses `currentColor`.
- The default value text is `text-sm`. On small rings, shrink it or leave **CircularProgressValueText** out.
- Keep `thickness` well below `size`, or the ring will not draw properly.
- The indeterminate spin turns off when the reader prefers reduced motion.

## Props

These are the props you set most often. Unlisted props pass through to the underlying element.

### CircularProgress

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `number or null` | `null` | Current value. `null` is indeterminate. Clamped to `min`–`max`. |
| `min` | `number` | `0` | Lowest value. |
| `max` | `number` | `100` | Highest value. |
| `getValueText` | `(value, min, max) => string` | Percentage | Text for screen readers and the default **CircularProgressValueText**. |
| `size` | `number` | `48` | Width and height in pixels. |
| `thickness` | `number` | `4` | Stroke width of the ring. |
| `render` | `ReactElement or function` | — | Replaces the root `div` with your own element. |
| `className` | `string` | — | Classes merged onto the root. |

### Data attributes

**CircularProgressIndicator**, **CircularProgressTrack** and **CircularProgressRange** set `data-state` to `indeterminate`, `loading` or `complete`, so you can style each state, for example `data-[state=complete]:text-chart-2`.
