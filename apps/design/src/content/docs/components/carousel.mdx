## Usage

Use a carousel to browse a short set of related items when space is tight, such as biomarker highlights or onboarding steps. Do not hide content the reader must see. Slides past the first are often missed, so put the most important item first. If the reader needs to compare items, use a grid instead.

Import it from `@workspace/ui/components/carousel`. It is built on [Embla Carousel](https://www.embla-carousel.com), so every Embla option works through `opts`.

```tsx
import {
  Carousel,
  CarouselContent,
  CarouselItem,
  CarouselNext,
  CarouselPrevious,
} from "@workspace/ui/components/carousel"
```

```tsx
<Carousel className="w-full max-w-xs">
  <CarouselContent>
    <CarouselItem>Vitamin D</CarouselItem>
    <CarouselItem>Ferritin</CarouselItem>
    <CarouselItem>HbA1c</CarouselItem>
  </CarouselContent>
  <CarouselPrevious />
  <CarouselNext />
</Carousel>
```

### Anatomy

- **Carousel** — The root. Holds the Embla instance and handles arrow keys.
- **CarouselContent** — The viewport and the track that slides.
- **CarouselItem** — One slide. Full width by default.
- **CarouselPrevious** — Button that moves back one slide. Disabled at the start.
- **CarouselNext** — Button that moves forward one slide. Disabled at the end.

### Notes

- The buttons sit outside the carousel, 48px from each edge. Leave room for them, or move them with `className`.
- Set slide width with a `basis-*` class on `CarouselItem`, for example `basis-1/3`.
- Spacing between slides comes from `ps-4` on each item and `-ms-4` on the track. Change both together.
- For a vertical carousel, give `CarouselContent` a fixed height.
- Use `useCarousel()` inside a child to build custom controls.

## Props

These are the props you set most often. Unlisted props pass through to the underlying element.

### Carousel

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | Direction the slides move. |
| `opts` | `EmblaOptionsType` | — | Embla options, such as `align` and `loop`. |
| `plugins` | `EmblaPluginType[]` | — | Embla plugins, such as autoplay. |
| `setApi` | `(api: CarouselApi) => void` | — | Receives the Embla API once it is ready. |
| `className` | `string` | — | Classes merged onto the element. |

### CarouselPrevious / CarouselNext

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `Button` variant | `"outline"` | Button style. |
| `size` | `Button` size | `"icon-sm"` | Button size. |
| `className` | `string` | — | Classes merged onto the button. |
